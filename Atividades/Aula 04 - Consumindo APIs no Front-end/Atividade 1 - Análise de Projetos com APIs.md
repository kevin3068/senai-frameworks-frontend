# Atividade 1 — Análise de Projetos com APIs

## Descrição

A atividade consistiu em pesquisar projetos disponíveis no GitHub que utilizam algum tipo de API em suas aplicações.

Após a pesquisa, os projetos foram clonados e analisados com o objetivo de identificar:

- O repositório utilizado;
- As tecnologias e frameworks presentes;
- As APIs consumidas pelas aplicações.

A tabela abaixo apresenta os projetos selecionados e suas respectivas informações.

## Análise dos Projetos

A análise dos repositórios permitiu observar que diferentes frameworks e linguagens podem ser utilizados no desenvolvimento de aplicações que consomem APIs.

Entre as tecnologias identificadas estão:

- React.js;
- Vue.js;
- Angular;
- Laravel;
- Node.js;
- TypeScript;
- Python;
- Kotlin;
- Go.

As APIs possuem diferentes finalidades, como:

- Consulta de dados sobre Pokémon;
- Consulta de informações meteorológicas;
- Autenticação de usuários;
- Armazenamento e gerenciamento de dados;
- Automação de fluxos de trabalho;
- Métricas e monitoramento;
- Criação de desenhos e quadros colaborativos;
- Gerenciamento de conteúdos;
- Controle de dispositivos e automações residenciais.

## Conclusão

A atividade possibilitou conhecer diferentes projetos reais disponíveis no GitHub e observar como as APIs são integradas às aplicações.

Ao clonar e analisar os repositórios, foi possível identificar as tecnologias utilizadas, compreender a estrutura dos projetos e verificar como cada aplicação realiza a comunicação com suas respectivas APIs.

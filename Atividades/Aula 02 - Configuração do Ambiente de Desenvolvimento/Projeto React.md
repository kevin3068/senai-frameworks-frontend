# Tic Tac Toe - Jogo da Velha

## Descrição

Este é o projeto da **aula 2** da matéria de **Frameworks Frontend** na instituição **SENAI Sorocaba**.

Um jogo da velha (Tic Tac Toe) simples desenvolvido com React.

## Como foi feito

O projeto foi criado seguindo os seguintes passos:

1. Instalação do **Node.js**
2. Criação do projeto com `npx create-react-app primeiro-projeto-react`
3. Desenvolvimento do jogo da velha
